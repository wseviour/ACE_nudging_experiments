# Technical Documentation: Upper-Level Nudging in ACE2 / FME

This document details the modifications made to the **ACE2 / FME (Fourier Forecasting Neural Operator)** codebase to support **blended stratospheric nudging** with configurable physical relaxation timescales.

---

## 1. Motivation and Scientific Background

In climate and numerical weather prediction, nudging (or Newtonian relaxation) is a standard technique used to constrain a model towards observed reanalysis (such as ERA5) in specific regions (e.g., the stratosphere), while allowing the rest of the atmosphere to evolve freely. 

This setup emulates the **Stratospheric Nudging And Predictable Surface Impacts (SNAPSI)** protocol ([Hitchcock et al., 2022](https://gmd.copernicus.org/articles/15/5073/2022/)) within a state-of-the-art machine learning foundation model. In ACE2:
- **Prescribed Nudging ($\tau = 0$):** The uppermost zonal wind level (`eastward_wind_0`, ~1 hPa) is completely replaced with ERA5 reanalysis at every 6-hour timestep.
- **Blended Relaxation Nudging ($\tau > 0$):** Rather than overriding the field completely, the new state is blended between the model's internal prediction and the reanalysis forcing according to an effective physical timescale $\tau$.
- **Free Forecast ($\tau = \infty$):** No nudging; the model evolves unconstrained.

---

## 2. Mathematical Formulation

### Discrete Blending Equation

At each autoregressive time step $t \to t + \Delta t$ (with $\Delta t = 6\,\text{h}$):

$$u(t + \Delta t) = w_{\text{model}} \cdot u_{\text{pred}}(t + \Delta t) + w_{\text{reanalysis}} \cdot u_{\text{reanalysis}}(t + \Delta t)$$

where:
- $u_{\text{pred}}(t + \Delta t)$ is the prognostically predicted state generated by the Spherical Fourier Neural Operator (SFNO).
- $u_{\text{reanalysis}}(t + \Delta t)$ is the observation / reanalysis field provided in the forcing dataset.
- $w_{\text{model}}$ (`model_weight`) is the weight applied to the model forecast ($0 \le w_{\text{model}} \le 1$).
- $w_{\text{reanalysis}}$ (`reanalysis_weight`) is the weight applied to the reanalysis ($0 \le w_{\text{reanalysis}} \le 1$).

### Physical Relaxation Timescale ($\tau$)

For a continuous Newtonian relaxation equation towards reanalysis $u_{\text{obs}}$:

$$\frac{\partial u}{\partial t} = -\frac{u - u_{\text{obs}}}{\tau}$$

Integrating over a discrete time step $\Delta t = 6\,\text{hours}$:

$$w_{\text{model}} = \exp\left(-\frac{\Delta t}{\tau}\right), \quad w_{\text{reanalysis}} = 1 - w_{\text{model}}$$

#### Key Regime Examples:
| Timescale ($\tau$) | Model Weight ($w_{\text{model}}$) | Reanalysis Weight ($w_{\text{reanalysis}}$) | Behavior |
| :--- | :--- | :--- | :--- |
| $\tau = 0$ | $0.000$ | $1.000$ | **Prescribed / Instantaneous** |
| $\tau \approx 8.66\,\text{h}$ | $0.500$ | $0.500$ | **Moderate Blending (50/50)** |
| $\tau = 24.0\,\text{h}$ (1 day) | $0.779$ | $0.221$ | **Weak Relaxation** |
| $\tau = 48.0\,\text{h}$ (2 days) | $0.882$ | $0.118$ | **Very Weak Relaxation** |
| $\tau \to \infty$ | $1.000$ | $0.000$ | **Free Forecast (No Nudging)** |

### 3.1. `fme.core.step.nudge.NudgeConfig`
A new configuration dataclass was added to define nudging parameters:

```python
@dataclasses.dataclass
class NudgeConfig:
    model_weight: float | None = None
    reanalysis_weight: float | None = None
    timescale_hours: float | None = None
    timescale_days: float | None = None
    timestep_hours: float = 6.0

    def __post_init__(self):
        if self.timescale_days is not None:
            self.timescale_hours = float(self.timescale_days) * 24.0

        if self.timescale_hours is not None:
            if self.timescale_hours <= 0:
                self.model_weight = 0.0
                self.reanalysis_weight = 1.0
            else:
                self.model_weight = math.exp(-self.timestep_hours / self.timescale_hours)
                self.reanalysis_weight = 1.0 - self.model_weight

        if self.model_weight is None or self.reanalysis_weight is None:
            raise ValueError("Either (model_weight, reanalysis_weight) or timescale_hours must be specified.")
```

### 3.2. Tensor Blending in `fme.core.step.single_module.step_with_adjustments`
After the neural network forward pass, denormalization, and ocean/atmosphere correction steps, prognostic variables in `nudged_prognostics` are blended with the reanalysis tensor:

```python
for name, nudge in nudged_prognostics.items():
    if name in next_step_input_data:
        reanalysis = next_step_input_data[name]
        if reanalysis.dtype != output[name].dtype or reanalysis.device != output[name].device:
            reanalysis = reanalysis.to(device=output[name].device, dtype=output[name].dtype)
        if reanalysis.shape != output[name].shape:
            reanalysis = reanalysis.expand_as(output[name])
        assert nudge.model_weight is not None and nudge.reanalysis_weight is not None
        blended = (
            nudge.model_weight * output[name]
            + nudge.reanalysis_weight * reanalysis
        )
        output = {**output, name: blended}
    else:
        raise ValueError(f"nudged_prognostic '{name}' not in next_step_input_data")
```

### 3.3. Stepper Overrides in `fme.ace.stepper.single_module`
The `StepperOverrideConfig` allows overriding the nudging behavior on pre-trained serialized model checkpoints at inference time without modifying the saved checkpoint file:

```yaml
stepper_override:
  ocean: "keep"
  nudged_prognostics:
    eastward_wind_0:
      timescale_hours: 24.0
```

When `stepper_override.nudged_prognostics` is provided:
1. `stepper.replace_nudged_prognostics(override_config.nudged_prognostics)` recursively updates the internal step configurations.
2. The stepper adds the nudged variable names to its required input forcing list so the data loader streams them from the forcing files.

### 3.4. GPU Memory Management
During checkpoint deserialization and stepper initialization, PyTorch's internal allocator can retain fragmented blocks. We added explicit `torch.cuda.empty_cache()` invocations after loading serialized checkpoints and before inference execution to maximize available GPU memory.
